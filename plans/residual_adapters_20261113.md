# 异构残差适配：队友图示的最小实验

状态：27次训练已完成；27项保存预测重算、27个检查点重载核验均通过。完整结果见 `outputs/residual_adapters_v1/结果解读.md`。

## 数据流

输入µV/100 → CBraMod共享结构 → H[B,C,P,200] → 三个残差分支 → 样本级权重融合 → 与H相加 → 原flatten、LayerNorm、Dropout、Linear任务头。

- 空间分支：LayerNorm、200→32投影、每时间块内的通道注意力（4头）、32→200零初始化输出。
- 时间分支：LayerNorm、200→32投影、各通道内的时间块深度卷积（核3）、32→200零初始化输出。短输入不拉长。
- 频谱分支：原始物理窗口的自然分辨率rFFT，0.5—90Hz，实部、虚部及log幅值；按通道归一化并投影到32维，与H的投影相加，再零初始化投影到200维。该分支保留整窗信息，区别于CBraMod已有的一秒局部谱。
- 门控：对H做通道和时间平均，LayerNorm、200→32→3、softmax，生成每样本三个权重。门控最后层零初始化，初始均匀。

三个残差分支输出初始为零，模型初始预测与原稠密模型相同。分支不额外使用dropout，以保持配对训练中原骨干和头的随机数消费路径一致。门控分类梯度在残差开始学习后验证非零。

空间/时间/频谱是结构上的归纳偏置名称，不能仅凭命名声称已分离相应生理机制。当前每数据集独立适配，尚未据此证明多任务共享有效。

## 三个新条件和复用基线

| 条件 | 活跃分支 | 融合 |
|---|---|---|
| baseline | 无新增分支 | 原有S组，复用9次配对单任务结果 |
| uniform | 空间、时间、频谱 | 固定各1/3 |
| learned | 空间、时间、频谱 | 学习的样本级softmax |
| no_spectrum | 空间、时间 | 同一三槽结构屏蔽频谱槽，剩余两槽softmax |

三任务×三折×三个新条件，共27次训练。三个条件保留相同的模块实例与总参数规模；uniform不更新门控，no_spectrum不更新或计算频谱分支，因此训练参数与激活计算量不同，需明确报告。

这是一种密集残差适配结构，不是之前的token级四同构专家稀疏FFN，也不宣称稀疏计算节省。

## 配对协议

- 使用现有P2开发折，排除旧测试被试。每折分别使用42/43/44训练种子，折与种子共同变化。
- 每数据集1500步，batch16，每100步验证。相同µV/100输入、训练折类别权重、AdamW、weight decay 0.01、余弦调度及验证BA选模。
- 骨干lr=1e-4，原分类头lr=1e-3，新增分支/门控lr=1e-3。适配器宽度32。
- 同一任务、同一折三个条件的骨干/头/分支初始张量与样本序列配对；差异只有启用分支及融合机制。
- 不改变滤波、时窗、标签映射或数据版本，不据旧测试调参，不增加门控均衡损失。

## 判读

uniform对baseline检验新增结构整体；learned对uniform检验学习融合；learned对no_spectrum检验频谱分支。no_spectrum与learned的激活容量不同，不能把差值完全归因为谱信息本身，后续需要等容量替代分支对照。

learned对uniform若有收益，仍不能单独证明“样本条件化”有效，因为全局可学习的三个常数权重也可能获得收益。届时再增加全局常数门控对照，避免把权重调优解释为内容自适应能力。

各任务分别报告逐折差值、均值、折间样本标准差、资源和门控分布。参数和协议均固定后再看结果；不因一个开发折上涨就认定有效，也不把失败结果藏起来。

当前预检已确认三任务各条件初始预测与baseline一致、头和骨干初始张量一致、禁用频谱时不执行FFT分支、门控和三个分支存在有限非零分类梯度。源码和配置快照随训练保留。
